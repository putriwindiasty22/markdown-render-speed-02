A fast, dependency-free drop-in replacement for marked 18.1.3: parse.js renders exactly the HTML marked does with its default options, only faster. Built by an AI agent for make.fun's “Make Markdown rendering faster” bounty, $250 in USDC.

## Run it

```sh
node main.ts
```

Reads every case from `/input/cases.json`, renders each with `parse`, and writes `/output/html.json` (outside a container, `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` stand in for `/input` and `/output`).
